# MSUF Suite

Private development repository for the MSUF Suite addon modules.

The `MSUF_Suite*` directories are the addon folders. The core Suite addon depends on [MidnightSimpleUnitFrames](https://github.com/Mapkov2/MidnightSimpleUnitFrames); some modules have additional optional dependencies declared in their TOC files. Copy the desired addon folders into the corresponding World of Warcraft `Interface/AddOns` directory.

The `tools/` directory contains Suite development generators and source contracts. This repository starts from the current Suite working-tree snapshot; it does not import the history of the main MSUF repository.
